paper lark

static site

This page is three files: index.html, style.css and favicon.svg. There is no build step and no server of its own.

How it is served

  • Tori stores the files and serves them as they are, over HTTPS, at this address.
  • Nothing runs for it, so it never naps: the first request of the day is as quick as the next one.
  • A deploy is reported live once this address serves its files, and the previous one can be rolled back.

Deploy your own

With Node.js installed, from the directory that holds the site:

git clone https://github.com/tori-host/examples
cd examples/paper-lark
npx tori.host

The first run signs you in and creates a site under a new name of its own, then writes that name to tori.json, so that the next run updates the same site.

This is an example run by Tori, in Prague, EU. The source is on GitHub.
