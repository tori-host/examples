How it checks

  • The list of examples is compiled into the server. Each check is one GET of a fixed address, looking for the marker the example's page carries, with a 5 s limit. A redirect counts as down and is not followed.
  • There is no timer. A visit runs a round of checks, all at once, when the last results are more than {{.MaxAge}} s old; otherwise it shows those. Visits that arrive during a round wait for it, so the examples are checked at most once a minute, however busy this page is.
  • The history is kept in memory only: up to the last {{.Keep}} rounds since this copy started, at {{.StartedAt.UTC.Format "2006-01-02 15:04"}} UTC ({{.Rounds}} so far). It is lost when the server restarts, and when nobody visits for a while the server naps, which is a restart.

Deploy your own

With Node.js installed:

git clone https://github.com/tori-host/examples
cd examples/steel-swift
npx tori.host

There is no Dockerfile. Tori finds go.mod beside Go code, builds the binary from the source and runs it, so Go does not need to be installed on your machine. The first run creates a service under a new name of its own and writes it to tori.json, so that the next run updates the same service.

This is an example run by Tori, in Prague, EU. The source is on GitHub.
