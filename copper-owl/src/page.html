copper owl

PHP server

An invoice, ready to print. Fill in the form and the server draws the invoice, with every line, the VAT for each rate and the total worked out in whole cents. Nothing you type is stored or logged.

{{main}}

How it runs

  • Plain PHP, no framework and no dependencies. There is no Dockerfile: Tori sees index.php, builds an image on FrankenPHP and runs it.
  • Every request goes to index.php, which answers the form, the invoice and the stylesheet. Nothing else in the directory is served.
  • Prices become whole minor units and quantities whole thousandths as they are read, so no sum on the invoice ever passes through a floating-point number.
  • An invoice is drawn for the browser that posted the form, and only for a form posted from this page. A link cannot show one.

Deploy your own

With Node.js installed (the CLI runs on it; the build runs on Tori):

git clone https://github.com/tori-host/examples
cd examples/copper-owl
npx tori.host

The first run creates a service under a new name of its own and writes it to tori.json, so that the next run updates the same service.

This is an example run by Tori, in Prague, EU. The source is on GitHub.
